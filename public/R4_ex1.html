Sujet 4 — Exercice 1 : Polynôme et Géométrie

Résolution d'équations dans $\mathbb{C}$, factorisation réelle et étude géométrique d'un quadrilatère inscrit.

5 points
1
Résolution de l'équation $(E) : z^2 - z + 1 = 0$
1
Calcul du discriminant ($\Delta$) :
Il s'agit d'une équation du second degré à coefficients réels avec $a=1$, $b=-1$, $c=1$.
$$\Delta = b^2 - 4ac = (-1)^2 - 4(1)(1) = 1 - 4 = -3$$
Puisque $\Delta < 0$, l'équation admet deux solutions complexes conjuguées.
2
Expression des solutions :
$$z_1 = \frac{-b + i\sqrt{-\Delta}}{2a} = \frac{1 + i\sqrt{3}}{2} = \frac{1}{2} + i\frac{\sqrt{3}}{2}$$ $$z_2 = \overline{z_1} = \frac{1 - i\sqrt{3}}{2} = \frac{1}{2} - i\frac{\sqrt{3}}{2}$$
✅
Les solutions de $(E)$ sont : $$S_{\mathbb{C}} = \left\{ \frac{1}{2} + i\frac{\sqrt{3}}{2} \;; \; \frac{1}{2} - i\frac{\sqrt{3}}{2} \right\} = \left\{ e^{i\frac{\pi}{3}} \;; \; e^{-i\frac{\pi}{3}} \right\}$$
2a
Factorisation de $P(z) = z^4 - z^2 + 1$
1
Méthode du début de carré parfait :
Nous pouvons exprimer le polynôme sous la forme d'une différence de deux carrés :
$$P(z) = (z^4 + 2z^2 + 1) - 3z^2$$
On reconnaît une identité remarquable dans la parenthèse :
$$P(z) = (z^2 + 1)^2 - (\sqrt{3}z)^2$$
2
Application de la formule $A^2 - B^2 = (A-B)(A+B)$ :
$$P(z) = (z^2 - \sqrt{3}z + 1)(z^2 + \sqrt{3}z + 1)$$
✅
Forme produit de deux polynômes du second degré à coefficients réels : $$P(z) = (z^2 - \sqrt{3}z + 1)(z^2 + \sqrt{3}z + 1)$$
2b
Résolution de $(E') : z^4 - z^2 + 1 = 0$
1
Utilisation de la factorisation précédente :
Un produit de facteurs est nul si et seulement si l'un des facteurs est nul. $$z^4 - z^2 + 1 = 0 \iff z^2 - \sqrt{3}z + 1 = 0 \quad\text{ou}\quad z^2 + \sqrt{3}z + 1 = 0$$
2
Résolution du premier facteur $z^2 - \sqrt{3}z + 1 = 0$ : $$\Delta_1 = (-\sqrt{3})^2 - 4(1)(1) = 3 - 4 = -1 = i^2$$ Les racines sont : $$z_A = \frac{\sqrt{3} + i}{2} \quad\text{et}\quad z_B = \frac{\sqrt{3} - i}{2}$$
3
Résolution du second facteur $z^2 + \sqrt{3}z + 1 = 0$ : $$\Delta_2 = (\sqrt{3})^2 - 4(1)(1) = 3 - 4 = -1 = i^2$$ Les racines sont : $$z_D = \frac{-\sqrt{3} + i}{2} \quad\text{et}\quad z_C = \frac{-\sqrt{3} - i}{2}$$
✅
L'équation $(E')$ possède 4 solutions complexes : $$S_{\mathbb{C}} = \left\{ \frac{\sqrt{3}+i}{2} \;; \; \frac{\sqrt{3}-i}{2} \;; \; \frac{-\sqrt{3}-i}{2} \;; \; \frac{-\sqrt{3}+i}{2} \right\}$$
3a
Placement des points $A$, $B$, $C$, $D$
1
Identification des affixes :
D'après les conditions de l'énoncé :
  • $\text{Re}(z_A) > 0$ et $\text{Im}(z_A) > 0 \implies z_A = \frac{\sqrt{3}+i}{2} = e^{i\frac{\pi}{6}}$
  • $\text{Re}(z_B) > 0 \implies z_B = \frac{\sqrt{3}-i}{2} = e^{-i\frac{\pi}{6}}$
  • $\text{Im}(z_D) > 0 \implies z_D = \frac{-\sqrt{3}+i}{2} = e^{i\frac{5\pi}{6}}$
  • Par élimination : $z_C = \frac{-\sqrt{3}-i}{2} = e^{-i\frac{5\pi}{6}}$
2
Position géométrique :
Tous ces points ont un module égal à 1 : $$|z_A| = |z_B| = |z_C| = |z_D| = 1$$ Ils appartiennent donc tous au **cercle unité** $\mathcal{C}$ de centre $O$ et de rayon $1$.
📍 Coordonnées cartésiennes
$$A\left(\frac{\sqrt{3}}{2}, \frac{1}{2}\right) \quad B\left(\frac{\sqrt{3}}{2}, -\frac{1}{2}\right) \quad C\left(-\frac{\sqrt{3}}{2}, -\frac{1}{2}\right) \quad D\left(-\frac{\sqrt{3}}{2}, \frac{1}{2}\right)$$ Les points $A$ et $B$ d'une part, $C$ et $D$ d'autre part sont symétriques par rapport à l'axe des abscisses.
3b
Nature du quadrilatère $ABCD$
1
Calcul des distances :
$$AB = |z_B - z_A| = \left| \frac{\sqrt{3}-i}{2} - \frac{\sqrt{3}+i}{2} \right| = |-i| = 1$$ $$CD = |z_D - z_C| = \left| \frac{-\sqrt{3}+i}{2} - \frac{-\sqrt{3}-i}{2} \right| = |i| = 1$$ $$BC = |z_C - z_B| = \left| \frac{-\sqrt{3}-i}{2} - \frac{\sqrt{3}-i}{2} \right| = |-\sqrt{3}| = \sqrt{3}$$ $$AD = |z_D - z_A| = \left| \frac{-\sqrt{3}+i}{2} - \frac{\sqrt{3}+i}{2} \right| = |-\sqrt{3}| = \sqrt{3}$$
On a $AB = CD = 1$ et $BC = AD = \sqrt{3}$. Les côtés opposés sont de même longueur, donc $ABCD$ est un **parallélogramme**.
2
Vérification de l'orthogonalité (ou des diagonales) :
Le milieu de $[AC]$ a pour affixe : $$z_I = \frac{z_A + z_C}{2} = \frac{\frac{\sqrt{3}+i}{2} + \frac{-\sqrt{3}-i}{2}}{2} = 0 = O$$ De même, le milieu de $[BD]$ est $O$. Les diagonales se coupent en leur milieu $O$, et : $$AC = |z_C - z_A| = |-\sqrt{3}-i| = \sqrt{3+1} = 2$$ $$BD = |z_D - z_B| = |-\sqrt{3}+i| = \sqrt{3+1} = 2$$ Les diagonales $[AC]$ et $[BD]$ sont de longueurs égales ($AC = BD = 2$).
✅
Puisque $ABCD$ est un parallélogramme dont les diagonales sont de même longueur, **$ABCD$ est un rectangle**. Ses dimensions sont de $1$ sur $\sqrt{3}$, et il est inscrit dans le cercle unité de diamètre $2$.

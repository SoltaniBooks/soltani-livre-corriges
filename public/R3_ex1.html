Exercice 1 : Nombres Complexes

Équation de degré 3 et Alignement

5 pts
Partie 1 — Résolution de l'équation $(E)$
Q1a

Vérification que $z = 2$ est solution de $(E)$

L'équation est : $(E):\ 2z^3-(7+5i)z^2+(4+14i)z+4-8i=0$

1
Substituons $z = 2$ dans $(E)$ :
Calcul
$2(2)^3 - (7+5i)(2)^2 + (4+14i)(2) + 4 - 8i$
$= 2(8) - (7+5i)(4) + (4+14i)(2) + 4 - 8i$
$= 16 - 28 - 20i + 8 + 28i + 4 - 8i$
$= (16 - 28 + 8 + 4) + i(-20 + 28 - 8)$
$= 0 + 0i = 0$ ✓
✅
$z = 2$ est bien solution de $(E)$.
Q1b

Détermination de $a$, $b$, $c$ tels que $(E) = (z-2)(az^2+bz+c)$

1
On développe $(z-2)(az^2+bz+c)$ : $$az^3 + bz^2 + cz - 2az^2 - 2bz - 2c = az^3 + (b-2a)z^2 + (c-2b)z - 2c$$
2
Identification des coefficients avec $2z^3 - (7+5i)z^2 + (4+14i)z + (4-8i)$ :
Identification
$\bullet\ a = 2$
$\bullet\ b - 2a = -(7+5i) \Rightarrow b = -(7+5i) + 4 = -3 - 5i$
$\bullet\ -2c = 4 - 8i \Rightarrow c = -2 + 4i$
3
Vérification : $c - 2b = (-2+4i) - 2(-3-5i) = -2+4i+6+10i = 4+14i$ ✓
✅
$a = 2,\quad b = -3-5i,\quad c = -2+4i$
Q1c

Résolution complète de $(E)$

1
On factorise : $(E) \Leftrightarrow (z-2)\bigl(2z^2-(3+5i)z+(-2+4i)\bigr)=0$
2
Calcul du discriminant de $2z^2-(3+5i)z+(-2+4i)$ :
Discriminant
$\Delta = (3+5i)^2 - 4(2)(-2+4i)$
$= 9 + 30i - 25 + 16 - 32i$
$= (9 - 25 + 16) + i(30 - 32)$
$= 0 - 2i = -2i$
3
Racine carrée de $\Delta = -2i$ : On cherche $(a+bi)^2 = -2i$. On vérifie que $(1-i)^2 = 1 - 2i - 1 = -2i$.
Donc $\sqrt{\Delta} = \pm(1-i)$.
4
Calcul des racines :
Racines
$z_1 = \dfrac{(3+5i)+(1-i)}{2 \times 2} = \dfrac{4+4i}{4} = 1+i$

$z_2 = \dfrac{(3+5i)-(1-i)}{4} = \dfrac{2+6i}{4} = \dfrac{1}{2}+\dfrac{3}{2}i$
✅
$$S = \left\{2\,;\; 1+i\,;\; \frac{1}{2}+\frac{3}{2}i\right\}$$
Partie 2 — Alignement des points $A$, $B$, $C$
Données
$z_A = 2$, $\quad z_B = \dfrac{1}{2}+\dfrac{3}{2}i$, $\quad z_C = 1+i$
Q2a

Calcul de $(z_C - z_A)\overline{(z_B - z_A)}$

1
$z_C - z_A = (1+i) - 2 = -1+i$
2
$z_B - z_A = \dfrac{1}{2}+\dfrac{3}{2}i - 2 = -\dfrac{3}{2}+\dfrac{3}{2}i$ $\quad\Rightarrow\quad \overline{z_B - z_A} = -\dfrac{3}{2}-\dfrac{3}{2}i$
3
Produit
$(-1+i)\!\left(-\dfrac{3}{2}-\dfrac{3}{2}i\right)$
$= \dfrac{3}{2} + \dfrac{3}{2}i - \dfrac{3}{2}i - \dfrac{3}{2}i^2$
$= \dfrac{3}{2} + 0 + \dfrac{3}{2} = 3 \in \mathbb{R}^*$
✅
$(z_C - z_A)\,\overline{(z_B - z_A)} = 3$
Q2b

Alignement des points $A$, $B$, $C$

Critère d'alignement
Trois points $A$, $B$, $C$ sont alignés si et seulement si $(z_C - z_A)\overline{(z_B - z_A)} \in \mathbb{R}$.

Ici $(z_C - z_A)\overline{(z_B - z_A)} = 3 \in \mathbb{R}^*$, donc les vecteurs $\overrightarrow{AC}$ et $\overrightarrow{AB}$ sont colinéaires.

✅
Les points $A$, $B$ et $C$ sont alignés.
Q2c

Homothétie et invariance de la droite $(AB)$

On considère la transformation $f$ définie par $z' = -\dfrac{1}{2}z + \dfrac{3}{2}(1+i)$.

1
Identification du type de transformation :
$z' - z_C = -\dfrac{1}{2}z + \dfrac{3}{2}(1+i) - (1+i) = -\dfrac{1}{2}z + \dfrac{1}{2}(1+i) = -\dfrac{1}{2}(z - z_C)$ ✓
2
Cette relation caractérise l'homothétie de centre $C$ et de rapport $k = -\dfrac{1}{2}$.
3
Invariance de $(AB)$ : Comme $C \in (AB)$ (alignement prouvé), le centre de l'homothétie appartient à $(AB)$. Tout point $M \in (AB)$ a son image $M' \in (AB)$. La droite $(AB)$ est donc globalement invariante par cette homothétie.
✅
$f$ est l'homothétie de centre $C(1+i)$ et de rapport $-\dfrac{1}{2}$.
La droite $(AB)$ est globalement invariante par $f$.
